# Deviations and implementation notes (after commit of analysis_plan_2026-11-16.md, SHA-256 b2b7079a...)

Each entry is written before the affected result is viewed.

1. **H2 complete cases (implementation detail, 2026-11-16).** The plan does not say how missing values are handled in H2. Genes with any missing promoter methylation, accessibility or expression value in the 73 tumours are excluded from H2, so that every model is fitted on the same tumours. Written before H2 was run.
2. **Bootstrap with leave-one-out (implementation detail, 2026-11-16).** Bootstrap resamples contain repeated tumours. Leave-one-out is applied per tumour, removing all copies of a tumour together. It is implemented as weighted least squares with multiplicity weights; the closed form was checked against a brute-force refit, matching to 1e-6. Written before H2 was run.
3. **Optimism correction (clarification, 2026-11-16).** All primary H2 statistics are already out-of-sample (leave-one-out CV R2), so no separate bootstrap optimism correction is applied to them. The bootstrap is used for confidence intervals. Written before H2 was run.
4. **Predictor scaling (implementation detail).** Methylation and accessibility are z-scored per gene before modelling. This does not change any R2 value.
5. **Technical-only model covariates (deviation, 2026-11-16).** The plan listed TCGA plate among the technical covariates. Plate is not available for the RNA-seq aliquots in the Xena matrix, and as a categorical variable it would use too many degrees of freedom for 73 tumours. The model uses ATAC deduplicated reads (log10), TSS enrichment, FRiP, duplicate fraction, sample-mean promoter methylation and array platform. Written before the model was run.
6. **Purity coverage (note).** ABSOLUTE purity is available for 71 of 74 tumours. The purity-adjusted H2 uses the tumours that have both methylation and purity.

## Entries written AFTER results.json was viewed (2026-11-16, ~14:15 UTC)

7. **H2 confidence intervals: bootstrap replaced by jackknife (deviation, post-results).** The pre-specified percentile bootstrap gave intervals that did not contain the point estimates. Example: median CV-R2 for accessibility 0.196, bootstrap interval 0.076 to 0.210; median MA - A -0.004, interval -0.023 to -0.011. The cause is structural. A bootstrap resample contains about 63% unique tumours (about 46 of 73), and leave-one-tumour-out CV-R2 falls with the number of distinct tumours. The bootstrap distribution therefore reflects a smaller study, not sampling variation at n = 73. The bias exceeds the spread, so the basic (reverse-percentile) correction also fails. H2 intervals are instead computed by a delete-one-tumour jackknife: the whole H2 computation is re-run 73 times with n = 72, and the interval is estimate +/- 1.96 x jackknife SE. The original bootstrap intervals are kept and reported in the supplement with this explanation. Point estimates are unchanged.
8. **H3 permutation test not evaluable (post-results).** Under permuted subtype labels, only 49 of 1000 permutations (all tumours) and 56 of 1000 (HM450 only) produced genes in both silenced sets, so the pre-specified statistic is undefined in most permutations. The resulting p-values (0.020, 0.018) rest on about 50 non-random draws and are not reported as tests. H3 is reported descriptively, with Wilson CIs as planned. Proportions are also tabulated among silenced genes that have both a promoter methylation value and a promoter peak, because genes lacking either measurement can only be classed "neither". This is a re-tabulation of the same classes, not a new analysis.
